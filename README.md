## 📝 Mes projets

- 🍽️​ [**Weekly-meal-plan-Generator**](https://github.com/yherlin67/Weekly-meal-plan-Generator) - Ce projet personnel est en cours de développement. Il s'agit d'un site web manipulant PHP et IA, servant à générer une liste de repas pour la semaine, à partir de différentes informations transmises. Il utilise les bibliothèques PHP Guzzle et Phpdotenv.

- 🪐 [**Stargate**](https://github.com/yherlin67/Stargate) - Ce projet a été réalisé en trinôme durant ma première année de BUT informatique. Il s'agit d'une application WinForms développée sur Visual Studio en C#, dans le cadre du framework .NET. De plus, elle manipule une base de données pour stocker différentes informations, à l'aide des classes ADO.NET intégrées au framework.

- 📶 [**Ethernet-network-Simulator**](https://github.com/yherlin67/Ethernet-network-Simulator) - Ce projet a été réalisé en trinôme dans le cadre de ma première année de BUT informatique. Il s'agit d'un simulateur de réseau Ethernet développé sur Visual Studio Code en C. L'utilisateur peut provoquer différentes actions dans un réseau (envoi de trames, déclenchement du protocole STP) en interagissant avec un menu, directement dans le terminal d'exécution.

- 🃏 [**Inscryption**](https://github.com/yherlin67/Inscryption) - Ce projet a été réalisé en binôme durant ma première année de BUT informatique. Il s'agit d'un jeu de stratégie et de construction de deck qui a été programmé sur l'IDE IntelliJ IDEA, dans le cadre de la programmation orientée objet en Java. Une partie se déroule directement dans la console Java intégrée à IntelliJ.

- ⛵ [**Booking-system-for-boat-trips**](https://github.com/yherlin67/Booking-system-for-boat-trips) - Ce projet a été réalisé en trinôme dans le cadre de ma première année de BUT informatique. Il s'agit d'un site web de gestion de réservation pour des trajets en bateau développé sur Visual Studio Code et qui manipule les langages HTML, CSS et JavaScript. De plus, il interroge une API à l'aide de requêtes asynchrones afin de récupérer différentes informations.
